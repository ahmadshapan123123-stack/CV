# Ahmad Shapan - Professional Interactive CV

A high-performance, interactive resume featuring a structured software lifecycle and custom architecture.

## Features
- Interactive Sidebar with Role-Based Focus.
- Dynamic Experience and Education sections linked via `data.js`.
- Clean, SEO-optimized technical copy.
- Print-ready A4 CSS layout.

## Technologies
- Tailwind CSS
- Vanilla JavaScript
- Animate.css / FontAwesome
